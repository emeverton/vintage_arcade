# Vintage Arcade — Interactive LP

Landing page interativa da Vintage Arcade, inspirada no gabinete arcade Midway Mortal Kombat II e no KV 3D da marca.

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Tailwind CSS

## Conceito visual

- **Marquee / cabeça do fliperama** = navegação principal
- **Tela** = hero section
- **Painel de controle** = features / proposta de valor
- **Coin door** = monetização, eventos e CTA final
- **KV central** = logo 3D da Vintage Arcade

## Rodar localmente

```bash
npm install
npm run dev
```
